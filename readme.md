<p align="center">
I work on the Game Development team at <b>ConveGenius AI</b>, taking classroom ideas from prototype to shipped product:<br/>
learning games, tools teachers can pick up without training, and the automations that keep them running.<br/>
Most of it lands on a shared tablet in a government school, so it has to be bilingual, light, and obvious.
</p>

Bilingual, voiced, landscape ready, light enough for a low-end classroom tablet.

</td><td valign="top" width="33%">

WhatsApp channel automation built on n8n and WAHA.

Running on Railway with Postgres behind it.
